### about

Student at **SRM Institute of Science and Technology**, studying Data Science, Database Management Systems and IoT through Embedded Systems.
I build end-to-end machine learning pipelines and the full-stack products around them. I enjoy strict constraints: tight metrics, runtime limits and messy real-world data.

### selected work

| project | what it is |
| :-- | :-- |
| **MediVision AI** | Multi-disease medical image analysis (chest X-ray, brain MRI, skin, retina, ECG). React, FastAPI, TensorFlow / PyTorch, PostgreSQL |
